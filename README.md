### about

my personal portfolio. built with plain html, css, and javascript.

six pages for my work, roblox games, education, and experience. plus a few small details i like — animations, a custom cursor, and a music player.

### files

```txt
portfolio-website/
├── index.html
├── favicon.svg
├── css/
│   └── styles.css
└── js/
    ├── boot.js
    ├── main.js
    └── games.js
```

### run locally

open `index.html` in your browser, or use a local server:

```bash
python3 -m http.server 8000
```

then visit `http://localhost:8000`.

### notes

the roblox games page loads public games and thumbnails through roblox endpoints. the music player uses youtube.
